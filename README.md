## 📌 About this project

## 🚀 How to use the graph

Once the application opens in your browser, you will see a canvas area. Use your mouse to interact with the visual elements:

* Click and drag the left mouse button to rotate your view of the graph.
* Use the scroll wheel to zoom in and out of the data points.
* Click on specific nodes to view detailed evidence reports.
* Use the menu sidebar to filter information by category.

The graph organizes information in layers. Higher nodes represent primary sources, while connected lines show relationships to secondary data. You can expand these nodes to reveal deeper layers of information as needed.

## 🖥 Troubleshooting common issues

If you face problems, check these items:

* Slow performance: Close other browser tabs to free up system resources. High graphic loads require significant memory.
* Missing labels: Refresh your browser page. This sometimes happens if a script fails to load properly during startup.
* Navigation confusion: Press the "Home" icon in the top corner to reset the camera view to the center of the graph.
* Update checks: Check the repository link periodically for new versions, as this tool receives frequent improvements for stability and data handling.
